## Report consolidation

JSON remains the authoritative report. The Markdown reading view exposes each request's declared scope, selection, applicability, execution, assessment, support/contrary/dependency references and limitations. Lint disclosures, qualification and currentness receive their own readable tables. Assessment retains the five conditions and fourteen fixed criteria, with the actual prerequisite states visible. Findings retain their scoped rule, premises and rule-generated needed information; the family code is not a severity ranking.

Exact integers and reduced fractions retain their existing denominators. Dossier strings are escaped; the complete inert report object remains included so no nested premise, partial inventory, witness or limitation is lost. Raw evidence bodies and locators stay in the original dossier. Saved canonical JSON renders the same Markdown as the in-memory report, including fixed case-pair and event-count ordering. A golden reading view protects readable order separately from whole-report JSON parity.

The existing 20 MiB delivery budget covers both canonical JSON and its expanded Markdown view. Either format exceeding the budget makes analysis return the same compact partial report, dropping undeliverable detailed basis and conclusions together. This closes a previously unmeasured Markdown-expansion boundary. Rendering an independently supplied saved report cannot silently change its conclusion; an oversized rendering is rejected instead. This is a delivery-boundary correction, with analytical rules and the numeric budget unchanged.
