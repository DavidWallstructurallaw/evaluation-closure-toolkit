## Report details and interpretation

All counts use numeric state wrappers. Available fractions use reduced decimal-string numerator/denominator pairs, a positive denominator, and `0/1` for zero. Undefined and unavailable values carry a reason and no numeric placeholder.

Profiles add membership and population completeness flags, reason counts, tail observations and an explicit `known_subset` object where required. These fields preserve the distinction between captured admitted counts and a complete population. Confirmed-valid absence applies only to the named qualified subset.

Comparison `before` and `after` identify the actual primary metric populations. `catalog_profiles` retains full selected and requested confirmed-valid profiles separately, including when the primary comparison is a fixed paired cohort. Planned pair counts and pair gaps remain visible if a contrast cannot be calculated. `new_observations` reports zero only for complete identical item rosters reannotated across frames; fresh IDs do not automatically establish new scientific observations.

Matching-basis reviews are filtered by exact comparison request before qualification, conflict handling or resolution. Assignment-resolution reviews retain explicit counterevidence and cannot replace a missing body, class, attribution or basis. Review indexes include all supplied matching declarations, including incomplete and wrong-scope records; they change lookup cost without selecting convenient evidence.

Explicit frame or snapshot disputes block direct comparison and complete-population loss conclusions, while their captured counts remain visible. Exact matching-basis opposition is considered even when logical item identities match. A positive complete baseline followed by a complete empty target can establish loss within that population; the target remains labeled `absent_in_empty_population` and supplies no model-incapacity conclusion.

If a resource limit interrupts a population scan, optional `partial_profiles` retains completed member and validity decisions with `resource_limit`. It carries no unfinished population totals, SCI/D or absence assertion. Already completed population profiles remain separate. Tail findings are grouped by state, with every class retained in the profile, so repeated full dependency lists cannot grow quadratically with the tail roster.

No policy text, class definitions, raw item bodies, pair-basis prose, evidence bodies or locators are copied into reports. Markdown presents exact quantities and retains the complete inert JSON report for detail parity.
